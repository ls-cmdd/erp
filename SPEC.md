# Project Specification

Flutter desktop ERP application. The README documents sales, purchasing, inventory, finance, human resources, reporting, and settings modules. Windows is the documented primary delivery target; the README also lists Linux and macOS, which should be verified by platform builds.

## Quality requirements
- Preserve business and financial data integrity.
- Require secure first-run administrator setup; do not rely on shared default credentials in production.
- Keep dependency resolution reproducible.
- Run analyzer, tests, and platform builds before release.

This initial specification is based on repository documentation and configuration; module-level acceptance criteria require further source review.
